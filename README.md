# Examen de Licencia de armas E

Aplicación gratuita para preparar el examen teórico de la licencia de armas E. Reúne un temario explicado de forma sencilla y **423 preguntas tipo test** basadas en los cuestionarios de la Guardia Civil.

## Qué puedes hacer

- **Estudiar:** consultar los 7 temas y sus explicaciones.
- **Simulacro:** responder 20 preguntas en 20 minutos, con corrección al finalizar.
- **Practicar examen:** responder sin límite de tiempo, con corrección inmediata.
- **Repasar errores:** volver a practicar las preguntas falladas.
- **Guardar o borrar el progreso:** tus datos se quedan en este navegador.

La aplicación no necesita servidor ni registro. Se puede instalar en el móvil y usar sin conexión después de cargar sus recursos.

## Aviso

Es una herramienta independiente de estudio, **no una página oficial de la Guardia Civil**. Para requisitos y normativa, consulta siempre las fuentes oficiales.
